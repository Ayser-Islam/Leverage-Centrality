## About

This repository contains the implementation and analysis of Leverage Centrality
for undirected and unweighted networks.

The notebook includes:

- Implementation of Leverage Centrality
- Analysis using Zachary's Karate Club network
- Visualization of Leverage Centrality
- Comparison of the top-ranked nodes across centrality measures
- Pearson, Spearman, and Kendall correlation analysis

The notebook accompanies the report:

**Leverage Centrality: A Local Perspective on Node Importance in Complex Networks**
